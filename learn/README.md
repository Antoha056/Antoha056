# Learn: Hello

Мини-фича для тренировки чтения кода.

## Как открыть (важно)

Не открывай файл через ссылку вида `vscode-remote://...` — браузер её не понимает (`ERR_NAME_NOT_RESOLVED`).

### Вариант A — на своём компьютере
1. Скачай/открой репозиторий локально.
2. Найди файл `learn/hello.html`.
3. Дважды кликни по нему **или** перетащи в окно Chrome/Firefox.
4. В адресной строке должно быть что-то вроде `file:///.../learn/hello.html`.

### Вариант B — простой сервер
В папке `learn` выполни:

```bash
python3 -m http.server 8765
```

Открой в браузере: http://127.0.0.1:8765/hello.html

## Что делает

1. Вводишь имя.
2. Жмёшь «Поздороваться».
3. Видишь приветствие — или ошибку, если имя пустое.
