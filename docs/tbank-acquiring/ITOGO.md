# Итого: этот платёж ещё не списан

`Success: true` и `ErrorCode: 0` значат только то, что **ответ банка валидный**. Деньги по заказу **49332682** пока **заморожены на карте**, не зачислены.

| Поле | Значение | Что это |
| --- | --- | --- |
| Status | `AUTHORIZED` | Двухстадийный эквайринг Т‑Банка: холд, ждать `Confirm` |
| Amount | `90000` | **900,00 ₽** (сумма в копейках) |
| Source / Route | `cards` / `ACQ` | Обычная оплата картой, не СБП и не счёт |
| PaymentId | `9167107039` | Идентификатор платежа в Т‑Банке |
| OrderId | `49332682` | Номер заказа в вашей системе |
| TerminalKey | `1579864014451` | Терминал мерчанта |

Заказ **нельзя** считать оплаченным и закрывать отгрузку, пока статус не станет `CONFIRMED`.

## Что сделать

1. Нужна полная оплата 900 ₽ — вызвать **Confirm** с `PaymentId=9167107039`. После успеха статус = `CONFIRMED`.
2. Нужна меньшая сумма — тот же Confirm, но с `Amount` в копейках (не больше 90000).
3. Отменить холд — **Cancel**. Деньги на карте покупателя разблокируются, статус = `CANCELED`.
4. Ничего не делать — через несколько дней холд сам спадёт (`DEADLINE_EXPIRED`), 900 ₽ вы не получите.

Проверка: `GetState` по `PaymentId`. Нужен `CONFIRMED`, не `AUTHORIZED`.
