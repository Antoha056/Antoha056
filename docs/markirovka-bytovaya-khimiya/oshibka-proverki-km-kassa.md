# Ошибка проверки КМ на кассе

Сообщение кассы «Ошибка проверки КМ, маркировка будет отвергнута. Необходимо уведомить бухгалтера» значит: фискальный накопитель **не принял код**, продавать эту единицу как обычный товар нельзя. Строка «Ошибок нет» относится к драйверу ККТ, а не к маркировке.

## Этот дамп

```
Ошибка проверки КМ, маркировка будет отвергнута.
Необходимо уведомить бухгалтера
0105413048311093215BTLoSntrqS?
"0 Ошибок нет"
CheckItemLocalResult 0
CheckItemLocalError 1
MarkingType2 3
KMServerErrorCode -1
KMServerCheckingStatus -1
```

| Поле | Значение | Что это |
| --- | --- | --- |
| КМ в логе | `0105413048311093215BTLoSntrqS?` | GTIN `05413048311093`, дальше серийник и обрывок. Криптохвоста не видно |
| `Ошибок нет` | код 0 драйвера | Команда до кассы дошла. Это не «КМ хороший» |
| CheckItemLocalResult | 0 | ФН **не смог** проверить код проверки |
| CheckItemLocalError | 1 | КМ **некорректного формата** (ошибка кодирования) |
| MarkingType2 | 3 | Тег 2100: AI 92 длиной 44, в ФН не проверяется. Для бытовой химии рабочий тип — **5** (AI 93) или **4** (AI 92/44, проверяется в ФН) |
| KMServerErrorCode / Status | -1 / -1 | Онлайн-проверка в «Честный знак» **не вызывалась** |

С 01.07.2026 маркированную бытовую химию выводят через кассу. Разрешительный режим, который блокирует продажу, для этой группы — с 01.04.2027. Поэтому 1С может **дать закрыть чек с отвергнутой маркировкой**. Так делать нельзя: в чеке будет [М-], вывод в ЧЗ не состоится, бухгалтеру потом разбирать расхождение.

## Какой КМ должен быть

Для косметики и бытовой химии серийник **ровно 6 символов** (первая — страна эмиссии, `5` или `E` — Россия). Между серийником и криптохвостом нужен разделитель **GS, ASCII 29**. В логе 1С он часто выглядит как `?`.

| Вид | Структура |
| --- | --- |
| Укороченный | `01` + GTIN 14 + `21` + серийник 6 + GS + `93` + 4 символа |
| Полный | `01` + GTIN 14 + `21` + серийник 6 + GS + `91` + 4 + GS + `92` + 44 символа |

В дампе после `21` идёт `5BTLoSntrqS?`: либо серийник длиннее 6 символов, либо сканер/касса съели GS и хвост, либо сообщение обрезалось на спецсимволе. Для ФН это один итог — формат неверный.

GTIN `05413048311093` начинается с префикса 541 (не 046). Так бывает у импорта. После ввоза на упаковке всё равно должен быть КМ «Честного знака», а не европейский Data Matrix без криптохвоста.

## Что делать на кассе

1. **Не** менять строку на артикул-остаток. Data Matrix на упаковке есть — это маркированный двойник.
2. **Не** закрывать чек, пока КМ «отвергнут».
3. Повторить скан **той же** единицы 2D-сканером. Не вводить код руками.
4. Если повтор прошёл (LocalError 0 и LocalResult 1) — оставить в чеке артикул-М и КИЗ.
5. Если ошибка та же — отложить единицу, пробить остальные позиции, вызвать ответственного.

Дальше смотрят не «на глаз», а по коду.

```
Повтор не прошёл
        │
        ▼
В КМ есть GS и хвост 93 или 91/92?
        │
        ├─ Нет  → сканер не отдаёт ASCII 29.
        │         IT настраивает GS1 Data Matrix.
        │         Единицу не продавать, пока скан не станет полным.
        │
        └─ Да   → проверить КМ в «Честном знаке»
                  │
                  ├─ Код наш и в обороте → брак обмена с ККТ, IT.
                  │                         Единицу отложить, не как остаток.
                  └─ Кода нет, чужой, брак печати → карантин.
                                                    Уведомить бухгалтера.
                                                    Возврат поставщику.
```

## Кто что делает

| Роль | Действие |
| --- | --- |
| Кассир | Повторный скан, не закрывать отвергнутый КМ, не подменять остатком, отложить единицу |
| IT | Сканер в COM / GS1 Data Matrix, передача GS (ASCII 29), тест в блокноте: между серийником и `93`/`91` должен быть непечатный разделитель. Проверить ФФД 1.2 и ключи проверки в ФН |
| Бухгалтер | Если чек уже закрыт с [М-] — не оставлять так. Корректировка или возврат, сверка с ЧЗ. Карантинную единицу в продажу не возвращать |

Проверка в приложении ЧЗ **не заменяет** проверку ФН. Код может быть «зелёным» в ЧЗ и красным на кассе, если сканер отдал КМ без GS.

## Чего не делать

- Не продавать эту банку как законный остаток: остаток — это упаковка **без** Data Matrix и с датой до этапа.
- Не закрывать чек с текстом «маркировка будет отвергнута».
- Не считать «Ошибок нет» успешной проверкой КМ.
- Не вводить КИЗ с клавиатуры и не отрезать «хвост».
- Не ждать 01.04.2027: обязанность передать КИЗ через кассу уже с 01.07.2026.
