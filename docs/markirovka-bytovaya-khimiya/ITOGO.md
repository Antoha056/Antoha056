# Итого

Один артикул и одна накладная остаются с одним статусом маркировки. Физический товар одного названия на складе при этом бывает двух видов: с Data Matrix и без. Их разводят **карточкой-двойником** и **сканом**, а дату «с какого момента обязателен код» считают по **паре ТН ВЭД + ОКПД 2**.

## 1. Сначала этап по кодам

Маркируется только товар в потребительской упаковке, у которого **оба** кода есть в перечне ПП РФ № 1681. Название на ценнике ничего не решает.

| Этап | Дата старта | ТН ВЭД | ОКПД 2 | Что это |
| --- | --- | --- | --- | --- |
| 1 | 01.05.2025 | 3401; 3402 50 000 0; 3405 40 000 0 | 20.41.3; 20.41.44; 20.42.19 | Мыло, моющие, бытовая химия |
| 2 | 01.07.2025 | 3305; 3307 (кроме 3307 41 000 0, 3307 90 000 1, 3307 90 000 2) | 20.41.41; 20.42.16; 20.42.17; 20.42.19 | Волосы, бритьё, дезодоранты, ароматизаторы |
| 3 | 01.10.2025 | 3304 (кроме антимикробной гигиены рук 3304 99 000 0); 3306 (кроме 3306 20 000 0) | 20.42.12; 20.42.13; 20.42.14 (кроме .120); 20.42.15 (кроме антимикробной гигиены рук); 20.42.18 (кроме .130) | Косметика, декоративка, полость рта |

Как ПО ставит дату:

1. Найти самую раннюю дату этапа для ТН ВЭД.
2. Найти самую раннюю дату этапа для ОКПД 2.
3. Контрольная дата = **поздняя** из двух. Если коды из разных волн — маркировка начинается, когда они пересекаются.
4. Нет пары в перечне или код в исключениях — товар не маркируется, двойник не нужен.

Код `20.42.19` есть и в 1, и во 2 этапе. Сам по себе дату не даёт: её даёт ТН ВЭД (3401 → 01.05.2025, 3305 или 3307 → 01.07.2025).

Омывающая жидкость маркируется только если в документах коды этапа 1. Часто это 3402 50 000 0 + 20.41.3. Код 3824 в перечень не входит.

## 2. Потом две карточки на один SKU

Правило ПО «артикул не бывает и маркированным, и нет» не ломаем.

На каждый такой SKU заводятся два внутренних артикула с общим EAN, именем и ценой:

- `ОМЫВ-5Л` — законный остаток, признак маркировки = нет, контрольная дата своего этапа;
- `ОМЫВ-5Л-М` — маркированный, признак маркировки = да.

Поиск по штрихкоду возвращает **пару**. Какую карточку взять, решает скан единицы, а не кладовщик «на глаз».

## 3. Скан на приёмке, сборке, кассе, списании на авто

- Есть Data Matrix → артикул-М.
- Нет кода, дата производства или ввоза **до** даты этапа → артикул-остаток. Продавать без кода до конца срока годности. Маркировать остаток не нужно.
- Нет кода, дата **после** этапа → карантин, возврат поставщику. Это уже не законный остаток.
- На «старой» упаковке код всё же есть → это маркированный товар, с 01.07.2026 его сканируют.

## 4. Как режутся документы

Пример: приехали 5 одинаковых канистр, 3 с кодом после даты этапа и 2 без кода до даты этапа.

ПО не пишет одну смешанную накладную. Получаются два однородных документа:

- приход 3 шт. на `ОМЫВ-5Л-М` + УПД ЭДО (GTIN и количество);
- приход 2 шт. на `ОМЫВ-5Л` без «Честного знака», со сроком годности.

| Документ | Можно смешать маркированный и остаток |
| --- | --- |
| Приход, расход, сборка, перемещение | Нет — две накладные |
| УПД в ЭДО / «Честный знак» | Нет — только маркированные строки, GTIN + количество |
| Кассовый чек с 01.07.2026 | Да — одна покупка, один чек. Нал и безнал одинаково |
| Складские движения из чека | Снова нет — чек режется на 1 или 2 однородных списания |

На авто: продажа клиенту — товарный чек (с КИЗ или без). Расход в работу — маркированный списывают ещё и в «Честный знак», остаток только со склада.

## 5. Чего не делать

- Не ставить одну дату на всю «бытовую химию».
- Не включать два статуса на одном артикуле.
- Не принимать смешанную поставку одной строкой «5 штук».
- Не маркировать законные остатки «на всякий случай».
- Не требовать КИЗ у остатка и не продавать без КИЗ то, что выпущено после даты этапа.
- Не делать два чека на одну покупку.
- Не закрывать чек, если касса пишет «маркировка будет отвергнута», и не менять такую банку на артикул-остаток.

## 6. Если касса отвергла КМ

Дамп `CheckItemLocalError 1`, `CheckItemLocalResult 0`, `KMServer* -1` — это **некорректный формат кода**, а не «связь с Честным знаком пропала». «Ошибок нет» — ответ драйвера ККТ. ФН код не принял.

Повторный скан той же единицы. Не проходит — отложить, проверить GS (ASCII 29) и криптохвост, затем «Честный знак». Продавать как остаток нельзя: Data Matrix на упаковке уже есть.

Разбор дампа и действия кассира, IT и бухгалтера: [ошибка проверки КМ](oshibka-proverki-km-kassa.md).

С 01.07.2026 касса и ЭДО одинаковы для всех трёх этапов. С 01.04.2027 для этой группы включается разрешительный режим на кассе.
