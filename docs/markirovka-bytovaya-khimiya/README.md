# Бытовая химия: маркированный и немаркированный товар одного артикула

**[Итого — читать сначала](ITOGO.md)**

## В чём конфликт

В ПО один артикул не может быть одновременно маркированным и немаркированным. Одна накладная тоже не может смешивать эти статусы.

По ПП РФ № 1681 один и тот же товар (один GTIN, один штрихкод, одно наименование) на складе законно существует в двух статусах:

| Статус | Когда так бывает | Что делать с кодом |
| --- | --- | --- |
| Немаркированный остаток | Произведён в РФ или ввезён **до** даты старта своей подгруппы | Продавать без Data Matrix **до окончания срока годности**. Маркировать остаток не нужно |
| Маркированный | Произведён или ввезён **после** этой даты | С 01.07.2026 сканировать Data Matrix на кассе и передавать вывод в «Честный знак» |

Дату на карточку **не ставят вручную одной цифрой на всю группу**. Её считает пара кодов ТН ВЭД + ОКПД 2:

| Этап | Дата | ТН ВЭД | ОКПД 2 | Что это |
| --- | --- | --- | --- | --- |
| 1 | **01.05.2025** | 3401; 3402 50 000 0; 3405 40 000 0 | 20.41.3; 20.41.44; 20.42.19 | Мыло, моющие, бытовая химия |
| 2 | **01.07.2025** | 3305; 3307 (кроме 3307 41 000 0, 3307 90 000 1, 3307 90 000 2) | 20.41.41; 20.42.16; 20.42.17; 20.42.19 | Волосы, бритьё, дезодоранты, ароматизаторы |
| 3 | **01.10.2025** | 3304 (кроме антимикробной гигиены рук 3304 99 000 0); 3306 (кроме 3306 20 000 0) | 20.42.12; 20.42.13; 20.42.14 (кроме .120); 20.42.15 (кроме антимикробной гигиены рук); 20.42.18 (кроме .130) | Косметика, декоративка, полость рта |

Нужны **оба** кода. Если они из разных волн — берётся более поздняя дата (когда коды пересекаются). Код `20.42.19` есть и в 1, и во 2 этапе: дату даёт ТН ВЭД. Полная таблица, исключения и алгоритм: [etapy-tnved-okpd2.md](etapy-tnved-okpd2.md).

Омывающая жидкость в примере ниже — только если в документах именно коды этапа 1 (часто это 3402 50 000 0 + 20.41.3). Код 3824 в перечень не входит, такой товар не маркируется.

Менять правило «один артикул = один признак маркировки» и «одна накладная = один статус» **не нужно**. Это правильный инвариант для документов и для «Честного знака». Нужно развести физический товар на **два внутренних артикула-двойника** и научить сканер решать, в какой из них класть единицу.

## Решение: карточка-двойник

На каждый SKU бытовой химии, по которому на складе могут быть оба статуса, заводятся две карточки с общей коммерческой связью.

```
Коммерческое имя:  Омывающая жидкость 5 л
EAN-13:            4601234567890          ← один штрихкод на обе карточки

ОМЫВ-5Л            признак маркировки = нет
                   тип = законный остаток
                   ТН ВЭД = 3402 50 000 0
                   ОКПД 2 = 20.41.32
                   этап = 1, контрольная дата = 01.05.2025
                   обязателен срок годности
                   парный артикул = ОМЫВ-5Л-М

ОМЫВ-5Л-М          признак маркировки = да
                   те же ТН ВЭД, ОКПД 2 и этап 1
                   товарная группа ЧЗ = косметика / бытовая химия
                   GTIN = 04601234567890
                   парный артикул = ОМЫВ-5Л
```

Поиск по штрихкоду возвращает **пару**, а не одну карточку. Какой из двух артикулов выбрать, решает не оператор «на глаз», а результат сканирования единицы.

```
Есть Data Matrix (КИЗ)     →  артикул-М
Нет Data Matrix,
дата производства до
контрольной                →  артикул-остаток
Нет Data Matrix,
дата после контрольной     →  карантин, возврат поставщику
                             (это уже не законный остаток)
```

Если на «старой» канистре код всё же нанесён — это маркированный товар. При продаже с 01.07.2026 его нужно сканировать.

## Пример: 5 канистр в одной поставке

Поставщик привёз 5 одинаковых канистр омывающей жидкости. Три произведены после 01.05.2025 (с Data Matrix), две — до (без кода).

```
Поставка поставщика, 5 шт. «омывайка 5 л»
        │
        ▼
Скан каждой единицы 2D-сканером
        │
        ├─ 3 шт. с Data Matrix  → буфер ОМЫВ-5Л-М
        └─ 2 шт. без кода,
           дата до 01.05.2025   → буфер ОМЫВ-5Л
        │
        ▼
ПО не пишет смешанную накладную.
Автоматически делает два однородных документа:

  Приход №1  ОМЫВ-5Л-М   3 шт.  + УПД ЭДО (GTIN + количество)
  Приход №2  ОМЫВ-5Л     2 шт.  без «Честного знака», со сроком годности
```

Внешний УПД поставщика при этом может быть один. С 01.07.2026 в объёмно-сортовом учёте в «Честный знак» уходят только **маркированные** строки: GTIN и количество. Немаркированный остаток в ЧЗ не передаётся. Внутренние накладные режутся по статусу, даже если «бумага» поставщика была общей.

## Где смешивать нельзя, а где можно

| Документ | Маркированный и остаток вместе | Почему |
| --- | --- | --- |
| Приходная накладная | Нет | Инвариант ПО, разные проводки в ЧЗ |
| Расходная / перемещение / сборка | Нет | Та же причина |
| УПД в ЭДО | Только маркированные строки в блоке ЧЗ | ОСУ: GTIN + количество |
| **Кассовый чек** | **Да, это нормально** | Одна покупка = один чек (54-ФЗ). В маркированных строках есть КИЗ, в строках остатка — нет |
| Складские движения из чека | Снова режутся на 1 или 2 однородных | Чек может быть смешанным, накладная — нет |

Если клиент берёт 2 канистры без кода и 1 с кодом:

- на кассе — **один** чек из трёх строк (две без КИЗ, одна с КИЗ);
- на складе — **два** списания: `ОМЫВ-5Л × 2` и `ОМЫВ-5Л-М × 1`.

Не делать два чека на одну покупку.

## Сканирование на каждой операции

2D-сканер — единственный классификатор статуса. Линейного EAN недостаточно, чтобы отличить канистры.

### Приёмка

1. Открыть поставку.
2. Сканировать **каждую** потребительскую упаковку, не принимать «по количеству».
3. Data Matrix → буфер артикула-М, проверить что GTIN совпадает с УПД.
4. Нет кода → считать дату производства / ввоза с этикетки или из документов партии.
5. После последней единицы сформировать одну или две однородные накладные.
6. Маркированную накладную закрыть подписанием УПД в ЭДО.
7. Нечитаемый код, чужой GTIN, код без даты после контрольной — в карантин, УПД не подписывать без акта расхождений.

До 01.07.2030 в УПД **не нужно** перечислять каждый КИЗ: достаточно GTIN и количества (ОСУ, ПП РФ № 656). Скан на приёмке всё равно нужен: иначе нельзя понять, какая канистра маркированная, и нельзя проверить, что код потом пробьётся на кассе.

### Сборка заказа

1. По штрихкоду / имени заказ видит **суммарный** остаток пары и разбивку: «2 без маркировки (срок до 03.2027), 3 с маркировкой».
2. Подбор по умолчанию: сначала законный остаток, FIFO по сроку годности. Остаток нельзя «домаркировать», он сгорит.
3. Сборщик сканирует фактическую единицу. ПО само ставит в строку нужный двойник.
4. Если в заказе был `ОМЫВ-5Л`, а отсканировали КИЗ — автозамена на `ОМЫВ-5Л-М` (и наоборот), без ручного пересоздания документа.
5. Если в одной сборке оказались оба статуса — система делает **две** расходные накладные, а не одну смешанную.

### Продажа в розницу, магазине запчастей, на СТО (нал и безнал)

С 01.07.2026 розничный вывод маркированного товара идёт **через ККТ**, способ оплаты не важен.

1. Кассир сканирует упаковку.
2. Есть Data Matrix — в чек идёт артикул-М и код маркировки, ОФД отдаёт сведения в ЧЗ.
3. Нет кода, карточка — законный остаток — в чек идёт артикул-остаток **без** тега маркировки. Сканировать «пустой» КИЗ нельзя и не нужно.
4. Нал и безнал бьются одинаково: меняется только признак расчёта, не логика маркировки.
5. Один чек может содержать оба типа строк. После пробития склад получает однородные движения.

Разрешительный режим на кассе для этой группы — с 01.04.2027. С 01.07.2026 касса уже обязана передать КИЗ, даже если ещё не блокирует продажу.

Если касса показывает «Ошибка проверки КМ, маркировка будет отвергнута»:

- В ошибке ПО **по умолчанию приписывает короткий КМ** (`MarkingType2 3`). На кассу при этом **приходит полный** (`91`/`92`).
- `CheckItemLocalError 1` — ФН сверил полный код с коротким шаблоном. «Ошибок нет» — только драйвер ККТ.
- В чеке при этом может быть **М**: позиция ушла как маркированная с отвергнутой проверкой. Это не М+ и не вывод в ЧЗ.
- Не подменять артикул-остатком. Незакрытый чек не пробивать; уже закрыт с М — сверка бухгалтера, не второй чек.
- Снять умолчание «короткий», слать полный как полный. Дальше: [ошибка проверки КМ](oshibka-proverki-km-kassa.md).

### Списание / заливка на авто

Сначала скан — тот же классификатор.

| Что сделали | Маркированный | Немаркированный остаток |
| --- | --- | --- |
| Продали клиенту отдельным товарным чеком | Чек ККТ с КИЗ, вывод как розница | Чек ККТ без КИЗ |
| Израсходовали в работе (материал, свои нужды) | Складское списание + вывод в ЧЗ **не через кассу**, ОСУ: GTIN + количество + причина | Только складское списание, в ЧЗ не отправлять |

Нельзя заранее выводить из оборота то, что ещё стоит на полке. Нельзя списывать маркированную канистру как обычный материал без отправки в ЧЗ — с 01.07.2026 это отдельная обязанность.

## Что сделать в ПО

Минимальный набор, без ломки инварианта накладной:

1. **Связь двойников** на карточке: `ПарныйАртикул`, общий EAN, ТН ВЭД, ОКПД 2, этап 1/2/3, контрольная дата, признак «законный остаток», товарная группа ЧЗ.
2. **Мастер создания пары:** по паре кодов посчитать этап и дату (справочник `etapy-tnved-okpd2.json`), затем завести два артикула. Старую карточку оставить остатком или маркированной — в зависимости от текущего остатка.
3. **Классификатор скана** на приёмке, сборке, кассе, списании: Data Matrix / только EAN / брак кода. На кассе вид КМ **не короткий по умолчанию**: `93` → короткий, `91`/`92` → полный, в ФН уходит тот же буфер.
4. **Авторазделение документов**: если в одном физическом потоке накопились оба буфера — две накладные из одной поставки или одной сборки.
5. **Автозамена двойника** в строке заказа по факту скана.
6. **Смешанный чек → однородные складские движения.**
7. **Инвентаризация перед 01.07.2026:** пройти склад сканером и разнести текущий остаток на два артикула. Документы на законный остаток (накладные, партия, дата производства/ввоза, срок годности) сохранить: сам факт «лежало на складе до июля» ничего не доказывает.

Печать ценников, название в чеке, цена и скидки у двойников одинаковые. Различаются только внутренний код, признак маркировки и движение в ЧЗ.

## Чего делать не надо

- Не включать на одном артикуле два статуса «как характеристику партии», если накладная и обмен с ЧЗ завязаны на признак карточки — это и есть текущий тупик.
- Не маркировать законные остатки «на всякий случай». Для косметики и бытовой химии маркировки остатков нет, продажа без кода разрешена до конца срока годности.
- Не принимать смешанную поставку одной строкой «5 штук омывайки».
- Не требовать КИЗ на кассе у законного остатка и не продавать без КИЗ то, что произведено после контрольной даты.
- Не закрывать чек, если КМ отвергнут, и не продавать такую единицу как остаток.
- Не считать букву М в чеке успешной проверкой: при этой ошибке это отвергнутая маркировка, не М+.
- Не зашивать на группу «всегда короткий КМ»: полный код с хвостом 91/92 нужно слать в кассу как полный.
- Не заводить разные розничные цены на двойников: это один товар для покупателя.
