# Antoha056

## Итого: маркировка бытовой химии

Полный ответ: [docs/markirovka-bytovaya-khimiya/ITOGO.md](docs/markirovka-bytovaya-khimiya/ITOGO.md)

Коротко: один артикул и одна накладная — один статус. Один SKU на складе бывает с Data Matrix и без. Их разводят карточкой-двойником. Дату этапа считают по паре ТН ВЭД + ОКПД 2 (01.05 / 01.07 / 01.10.2025). Скан кладёт единицу на остаток или на маркированный артикул. Смешанная поставка режется на две накладные. Кассовый чек с 01.07.2026 может быть смешанным.

Если касса пишет «ошибка проверки КМ, маркировка будет отвергнута» — в ошибке по умолчанию короткий тип, на ФН приходит полный. В чеке при этом может быть М: это не успех проверки. Разбор: [docs/markirovka-bytovaya-khimiya/oshibka-proverki-km-kassa.md](docs/markirovka-bytovaya-khimiya/oshibka-proverki-km-kassa.md).
